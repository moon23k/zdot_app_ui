포인트 컬러 절제 · 선택 표시 개편. 새 색 토큰 recess(가라앉은 면) · raised(떠오른 면) · line(옅은 선) · faint(흐린 글자) · disabledSurface · disabledForeground · arc · arcMuted · focusRing, 새 그림자 shadow.lift · shadow.liftSm. Button — 주 버튼 · 위험 버튼 비활성은 disabledSurface 바탕 + disabledForeground 글자(흐림 없음, 줄어듦 유지), sm 주 버튼도 primary 채움 + 흰 글자. Field — 반경 lg, 평소 surface + 1px line, 입력 중 1px primary + 4px focusRing 번짐 · primary 커서(오류 · 경고는 그대로). SearchField — 테두리 없는 raised + lift. Chip · ChipGroup — 안 고른 칩 recess + mutedForeground, 고른 칩 raised + liftSm + 600 + 글자 앞 지름 6 primary 점(check 칩은 체크 그대로). CircleGrid — 고른 원은 primary 테 대신 4px raised 테 + lift, 오른쪽 아래 지름 24 체크 원(바탕색 테 2.5). QuestionPager — 탭 아래 line, 지금 탭 title + primary 밑줄, 끝난 탭 mutedForeground + primary 체크, 남은 탭 faint, 타일은 recess + mutedForeground, 고른 타일 raised + liftSm + 600 + 지름 18 체크 원. DialStrip · AxisRing — 링 바탕 recess · 테 line, 고른 축만 raised + liftSm, 호 arc(고른 축) · arcMuted, 색 링은 고른 것 raised 테 + liftSm. ColorFamilyTabs — 고른 견본은 4px raised 테 + liftSm. PaletteThumbs · DraftStrip — 고른 썸네일은 raised 테 + lift + 체크 원. BlockStrip — 번호 배지 raised + liftSm + title 글자(고른 블록은 primary 배지 · raised 테 + lift). ToolRow 켜짐 raised + liftSm + title 아이콘, EditorBar · FontPicker 켜짐 recess, ColorSwatchPicker · LayoutPicker · StructurePicker 고른 것 raised 테 + 그림자. props · 동작 · 접근성 변경 없음.
